# Project memory

## Git commit attribution

When creating a Git commit, include a `Co-Authored-By` trailer identifying the AI model that contributed to the change.

For GPT 6.1 Sol, use this exact trailer:

```text
Co-Authored-By: GPT 6.1 Sol <codex@openai.com>
```

Use the actual model name when a different model contributes. Keep the configured human Git author and committer identity.
